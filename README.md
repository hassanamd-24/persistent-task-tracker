# Persistent Task Tracker

A sleek, responsive, and minimalist To-Do List web application built entirely with **Vanilla JavaScript, HTML5, and CSS3**. This project focuses on a clean user experience paired with persistent data retention.

## 🚀 Live Demo
🔗 **[Click Here to View the Live Web App](https://hassanamd-24.github.io/persistent-task-tracker/)**

## ✨ Key Features
* **Data Persistence:** Utilizes the Web Storage API (`localStorage`) to save your task list so it remains intact even after closing or refreshing the browser.
* **Batch Operations:** Features a dedicated "Clear All" action to instantly reset your task board.
* **Modern Interface:** Built with a clean, centered dark-themed card UI for distraction-free productivity.

## 🛠️ Technologies Used
* **HTML5:** Semantic layout structure and user input handling.
* **CSS3:** Custom dark mode styling, flexbox layouts, smooth transitions, and UI button configurations.
* **JavaScript (ES6+):** Event listeners, dynamic DOM manipulation, and local storage integration.

## 💡 Technical Takeaways
Through this project, I strengthened my core understanding of working with arrays in local storage, implementing user input validation to prevent empty tasks, and managing application state dynamically without relying on front-end frameworks.
